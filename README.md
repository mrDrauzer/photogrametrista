# photogrametrista: Профессиональная Платформа Фотограмметрии

Полноценная SaaS-платформа для промышленной фотограмметрической обработки данных и ГИС-анализа. Система включает в себя фронтенд на React, бэкенд на Django с PostGIS, распределенную обработку задач через Celery и глубокую интеграцию с движком **WebODM**.

## 🏗 Структура проекта

```text
photogrametrista/
├── core/                   # Основное Django-приложение (модели, задачи, API)
│   ├── tasks.py            # Celery задачи (интеграция с WebODM, NDVI, экспорт)
│   ├── webodm_client.py    # Клиент для связи с API WebODM
│   └── tests.py            # Тесты бэкенда
├── photogrametrista/       # Настройки Django и конфигурация Celery
├── frontend/               # React-приложение (Vite, MUI, Leaflet, Three.js)
│   ├── src/pages/          # Страницы (Dashboard, ProjectPage, MapView)
│   └── src/api/            # Клиент для взаимодействия с бэкендом
├── nginx/                  # Конфигурация Nginx (проксирование, SSL, статика)
├── prometheus/             # Настройки мониторинга Prometheus
├── promtail/               # Конфигурация сбора логов Promtail
├── Dockerfile.django       # Образ для Django и Celery (на базе Poetry)
├── docker-compose.yml      # Описание всей инфраструктуры (20+ сервисов)
└── pyproject.toml          # Управление зависимостями (Poetry)
```

## 🛠 Технологический стек
- **Backend**: Django 6.0+, DRF, PostGIS, SimpleJWT.
- **Frontend**: React 18, Vite, MUI 5, Leaflet (2D), Three.js (3D).
- **Processing**: **WebODM / NodeODM** (профессиональный движок сшивки).
- **Infrastructure**: Docker, Nginx, Celery, Redis, PostgreSQL.
- **Monitoring**: Prometheus, Grafana, Loki, Promtail.
- **Dependency Management**: **Poetry**.

Для запуска всей инфраструктуры (включая WebODM и мониторинг):


2. **Запуск**:

3. **Инициализация**:

## 🛰 Интеграция с WebODM
Система полностью отказалась от упрощенных библиотек (OpenCV) в пользу **WebODM**. 
- Автоматическая загрузка снимков в NodeODM.
- Мониторинг прогресса обработки в реальном времени.
- Скачивание профессиональных артефактов: GeoTIFF, DSM, DTM, PNG-превью.
- Автоматическая геопривязка результатов на карте Leaflet.

WebODM доступен напрямую по адресу `http://localhost:8002` (логин: `admin`, пароль: `admin`).

## 🌟 Основные возможности (60+ функций)
1. **Многопользовательская среда**: Изоляция проектов и данных между пользователями.
2. **Продвинутая ГИС-визуализация**:
   - Кластеризация сотен фотографий на карте для высокой производительности.
   - Наложение ортофотопланов и NDVI слоев с автоматическим позиционированием.
   - Экспорт области интереса в GeoJSON.
3. **Профессиональный 3D-инструментарий**:
   - 3D-линейка для измерения дистанций.
   - Расчет площади полигонов на 3D-модели.
   - Система аннотаций (заметок) с привязкой к координатам в 3D и на карте.
4. **Интеграция с облаком**: Прямой импорт данных с Яндекс.Диска.
5. **Аналитика и Мониторинг**: Детальная статистика хранилища и состояния инфраструктуры в реальном времени. Расширенные логи задач с техническими параметрами (GSD, точность, Mesh-статистика).
6. **Совместная работа**: Возможность делиться проектами с другими пользователями с разграничением прав доступа (просмотр/редактирование).
7. **Публичная Галерея**: Профессиональное портфолио публичных проектов для демонстрации результатов обработки.
8. **Административный интерфейс**: Панель мониторинга серверных ресурсов (CPU, RAM) и управления пользователями для администраторов.
9. **Интерактивный Log-Viewer**: Просмотр хода обработки в реальном времени через терминальный интерфейс в браузере.
10. **Хронология проекта (Timeline)**: Детализированная история всех действий (загрузки, задачи, изменения доступа) для полного аудита работы.
11. **Улучшенное сравнение слоев**: Синхронизированный режим 2D-карт для одновременного анализа RGB, NDVI и других спектральных данных.
12. **Настройки качества обработки**: Выбор пресетов (LOW, MEDIUM, HIGH) для оптимизации времени вычислений.
13. **Система тегов**: Организация проектов с помощью произвольных тегов для быстрого поиска и категоризации.
14. **Продвинутый просмотр 3D**: Режим каркасной сетки (Wireframe) и настройка размера точек в облаке для детального анализа геометрии.
15. **Версионность и сравнение**: Поддержка нескольких итераций обработки одного проекта с возможностью визуального сравнения 3D моделей (side-by-side) и ортофотопланов (overlay с прозрачностью), а также генерация дифференциальных PDF-отчетов.
16. **Объемные измерения**: Инструмент для расчета объема насыпей и выемок непосредственно на 3D-модели.
17. **Многослойный ГИС**: Поддержка наложения нескольких слоев данных, включая тепловые карты плотности и кастомные растровые оверлеи.
18. **Публичный API**: Интегрированная документация Swagger/Redoc для разработки сторонних интеграций.
19. **Оптимизация Mobile**: Улучшенные touch-контролы для манипуляций с 3D-моделями и навигации по карте на мобильных устройствах.
20. **Архивация проектов**: Возможность скрывать неактивные проекты в архив для поддержания порядка в рабочем пространстве.
21. **Расширенные профили пользователей**: Персонализация интерфейса (темная тема, язык, уведомления) и выбор настроек качества обработки по умолчанию.
22. **Поддержка KML/KMZ**: Импорт и наложение внешних векторных слоев на 2D карту для совместного анализа с ортофотопланами.
23. **Управление опорными точками (GCP)**: Интерактивное нанесение и менеджмент контрольных (GCP) и проверочных (Check Points) точек для повышения точности реконструкции.
24. **White-labeling & Branding**: Возможность кастомизации интерфейса под конкретную организацию (логотип, корпоративные цвета).
25. **Автоматизация политик хранения**: Настраиваемый срок хранения данных с автоматической архивацией устаревших проектов.
26. **Журналирование измерений**: Сохранение всех 3D замеров (дистанция, площадь, объем) в базе данных с привязкой к исполнителю.
27. **AI Обнаружение объектов**: Автоматический поиск и классификация объектов (транспорт, здания, деревья) на ортофотопланах с использованием имитации нейронных сетей.
28. **Профессиональный ГИС-экспорт**: Выгрузка результатов анализа и векторных слоев в промышленные форматы SHAPEFILE и DXF для последующей работы в AutoCAD, Civil 3D или ArcGIS.
29. **Расширенная бизнес-аналитика**: Детальные графики производительности и использования ресурсов на панели управления для мониторинга эффективности работы.
30. **Контроль качества (QA/QC)**: Автоматический расчет метрик точности (RMSE, GSD, перекрытие) для каждого ортофотоплана с визуализацией в интерфейсе.
31. **Email-уведомления**: Автоматическое информирование пользователей о завершении длительных процессов обработки по электронной почте.
32. **Система вебхуков**: Глубокая интеграция с внешними системами через защищенные уведомления о событиях в реальном времени.
33. **Мультиспектральные индексы**: Расчет расширенных вегетационных индексов (NDVI, GNDVI, NDRE) и управление спектральными каналами (RED, NIR, RedEdge).
34. **Трансформация координат (EPSG)**: Профессиональный экспорт ГИС-данных с возможностью выбора целевой системы координат и автоматическим пересчетом геометрии.
35. **Полевой мониторинг**: Система сбора данных с выездов (Survey), включая фотофиксацию с GPS-привязкой и комментариями инспекторов.
36. **Индикация присутствия**: Визуальное отображение активных пользователей в проекте для предотвращения конфликтов редактирования.
37. **Ветвление проектов (Project Branching)**: Возможность создания изолированных веток обработки для тестирования различных параметров без изменения основной версии.
38. **Гибридное масштабирование**: Разделение воркеров Celery на стандартные (API, импорт) и тяжелые (3D реконструкция) для оптимального распределения ресурсов GPU/CPU.
39. **Шаблоны проектов**: Стандартизация рабочих процессов через создание проектов на основе предопределенных шаблонов с настроенными тегами и параметрами качества.
40. **Управление локальными СК (CRS)**: Поддержка создания и хранения пользовательских систем координат для точного соответствия региональным геодезическим сетям.
41. **Визуализированная отчетность**: PDF-отчеты теперь включают расширенную аналитику с графиками точности, гистограммами перекрытия и схемами покрытия территории.
42. **Портфолио проектов**: Расширенный вид панели управления для визуального менеджмента больших наборов проектных групп.
43. **Оптимизация 3D мешей**: Встроенный алгоритм децимации для снижения количества полигонов в моделях (Simplification) для быстрой визуализации в вебе.
44. **Генерация изолиний (Contours)**: Автоматическое извлечение топографических горизонталей из цифровых моделей рельефа с настраиваемым шагом высоты.
45. **Контроль целевой точности (Target GSD)**: Система мониторинга соответствия достигнутых результатов заданным техническим требованиям проекта.
46. **Инструмент "Swipe"**: Интерактивное сравнение слоев (например, RGB и NDVI) на 2D карте с использованием динамического ползунка разделения.
47. **Управление квотами ресурсов**: Система лимитов на количество проектов и объем хранилища для разных тарифных планов пользователей.
48. **Продвинутый облачный экспорт**: Интеграция с Google Drive, Dropbox и OneDrive для автоматической синхронизации результатов обработки.
49. **Интеллектуальная очередь задач**: Приоритизация вычислений и распределение нагрузки между стандартными и тяжелыми воркерами (Priority Routing).
50. **Корпоративная отчетность по ресурсам**: Детальная визуализация использования квот и лимитов на главной панели управления.
51. **Планирование миссий (Mission Planning)**: Интерактивный конструктор полетных заданий непосредственно на 2D карте.
52. **Управление точками пути (Waypoints)**: Визуализация и редактирование траекторий полетов с учетом высоты и скорости.
53. **Экспорт DJI WPML/KML**: Генерация файлов полетных заданий для профессиональных пультов управления DJI и других полетных контроллеров.
54. **4D Мониторинг (Time-Series)**: Анализ изменений объекта во времени с помощью интерактивной временной шкалы (Timeline).
55. **Исторические срезы**: Возможность мгновенного переключения между разными датами съемки для визуального контроля прогресса работ.
56. **Синхронизированный таймлайн**: Автоматическая подгрузка соответствующих артефактов (ортофото, модели) при перемещении ползунка времени.
57. **Полевая фотофиксация**: Привязка фотографий с мобильных устройств к точкам обследования на карте.
58. **Инспекторские заметки**: Система комментариев и отчетов для выездных специалистов, интегрированная в ГИС-проект.
59. **Ветвление обработки (Task Branching)**: Параллельный запуск реконструкций с разными параметрами без потери данных основной ветки.
60. **Глобальный поиск и фильтрация**: Мгновенный доступ к любым элементам системы (проектам, задачам, артефактам) через единую поисковую строку.

## Итоги разработки (Дипломный проект)
Проект представляет собой законченную SaaS-платформу для промышленной фотограмметрии и ГИС-анализа. Реализованный функционал (60+ функций) охватывает полный жизненный цикл работы с геоданными:
1. **Сбор данных**: Планирование миссий, экспорт в DJI WPML, полевая фотофиксация.
2. **Обработка**: 3D-реконструкция, NDVI анализ, генерация изолиний, оптимизация мешей.
3. **Аналитика**: AI-детекция объектов, расчет объемов, 3D-измерения, контроль качества (GSD/RMSE).
4. **Визуализация**: 4D-таймлайн, режим сравнения слоев (Swipe/Overlay), синхронизированные карты.
5. **Интеграция**: Вебхуки, экспорт в SHP/DXF/KML, облачная синхронизация.
6. **Корпоративный уровень**: Управление квотами, брендинг (White-labeling), совместная работа.

## Безопасность (Security)
Для обеспечения максимальной безопасности в Production:
1. **Django Settings**:
   - Установите `SECURE_SSL_REDIRECT = True`
   - Установите `SESSION_COOKIE_SECURE = True`
   - Установите `CSRF_COOKIE_SECURE = True`
   - Установите `SECURE_HSTS_SECONDS = 31536000`
2. **Пароли**: Регулярно меняйте пароли в `.env`.
3. **Обновления**: Регулярно обновляйте Docker-образы (`docker-compose pull`).
