# Быстрый старт (Локальная демонстрация)

Инструкция по быстрому развертыванию проекта «photogrametrista» для ознакомления и защиты диплома.

## 🚀 Запуск системы

### 1. Подготовка окружения
Склонируйте репозиторий и создайте файл конфигурации:
```powershell
cp .env.example .env
```
*Примечание: В шаблоне `.env.example` уже установлены демонстрационные пароли `admin` и параметр `COMPOSE_PROJECT_NAME=photogrametrista`. Последний важен для Windows, чтобы избежать ошибок именования образов Docker (invalid reference format).*

### 2. Запуск контейнеров
Соберите и запустите все сервисы через Docker Compose:
```powershell
docker-compose up -d --build
```
*Сборка фронтенда и скачивание образов БД может занять 2-5 минут.*

### 3. Инициализация данных
Выполните миграции и создайте учетную запись администратора с полным набором прав и квот:
```powershell
# Применение миграций
docker-compose exec django-app python manage.py migrate

# Создание демо-админа (логин: admin / пароль: admin)
docker-compose exec django-app python create_demo_admin.py
```

## ✅ План проверки функционала (Чек-лист)

Для демонстрации возможностей системы рекомендуется выполнить следующие действия:

1.  **Авторизация**: Войдите в систему под учетными данными `admin`/`admin`.
2.  **Создание проекта**: Нажмите «+» в боковой панели, введите название и выберите шаблон (например, «Маркшейдерия»).
3.  **Область интереса**: На карте выберите инструмент «Многоугольник» и нарисуйте границы участка.
4.  **Загрузка данных**: Во вкладке «Инфо» нажмите «Загрузить локально» и выберите несколько фотографий с геопривязкой (или используйте «Импорт из облака» для симуляции).
5.  **Запуск обработки**: Выберите качество «LOW» (для скорости) и нажмите «Запустить обработку».
6.  **Мониторинг**: Откройте вкладку «Задачи» или нажмите на иконку терминала в шапке, чтобы увидеть технические логи процесса в реальном времени.
7.  **Анализ результатов**: После завершения задачи перейдите во вкладки «Результаты», «Качество» или «GCP» для просмотра сгенерированных данных и метрик точности.
8.  **3D Визуализация**: Переключитесь в режим 3D, используйте инструменты «Линейка», «Площадь» или «Объем» для проведения замеров.

## 🛠 Устранение неполадок

*   **Контейнеры не стартуют**: Убедитесь, что порты 80, 443, 3000 и 5432 не заняты другими приложениями.
*   **Ошибка базы данных**: Если вы меняли пароли в `.env`, удалите старый том данных командой `docker-compose down -v` и запустите заново.
*   **Логи сервисов**: Для просмотра ошибок конкретного модуля используйте `docker-compose logs -f django-app`.
